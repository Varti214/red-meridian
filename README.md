# Красный меридиан

Браузерная гранд-стратегия в духе Hearts of Iron IV. Современный мир с 1 января 2018 года: Россия, США
и Китай соперничают за влияние. У каждой страны есть правящая идеология, лидер (реальные политики 2018 года)
и популярность партий; в демократиях проходят выборы по реальному календарю. Дальше историю пишет игрок:
фокусы, выборы, вмешательство и перевороты могут привести к власти других людей и сменить идеологию.

## Как запустить

**Самый простой способ** — дважды кликнуть по `index.html`. Интернет не нужен: 3D-движок и карта мира
лежат в папке проекта.

**Через локальный сервер** (если браузер что-то блокирует для файлов с диска):

```bash
python -m http.server 5084 --directory red-meridian
```

После этого откройте http://localhost:5084

Нужен современный браузер для компьютера (Chrome, Edge, Firefox). Если видеокарта не поддерживает WebGL,
игра сама переключится на 2D-карту.

## Сетевая игра (до 3 игроков)

Каждый игрок выбирает державу: **Россию**, **США**, **Китай** или **Украину** (до 4 игроков). Блок, который никто не выбрал,
ведёт ИИ. Сервер сам считает игровые дни, поэтому игра не встанет, если у кого-то свернулась вкладка.
Если все отключились, игра встаёт на паузу.

**Локально** (проверить на своём компьютере): `npm install`, затем `npm start`, затем откройте http://localhost:5085

**В интернете** через бесплатный [Render](https://render.com):
1. Загрузите папку проекта в репозиторий GitHub.
2. На render.com войдите через GitHub → **New → Blueprint** → выберите репозиторий. Настройки возьмутся из `render.yaml`.
3. Через пару минут появится адрес вида `https://red-meridian-xxxx.onrender.com`. Отправьте его другу.
4. Оба открывают адрес → «Сетевая игра» → один создаёт комнату, второй вводит код.

Бесплатный сервер засыпает через 15 минут без игроков и просыпается примерно за минуту при первом заходе.
Комната без игроков удаляется через 20 минут.

## Как играть

| Действие | Как |
|---|---|
| Пауза / продолжить | Пробел или кнопка ▶ |
| Скорость | `+` / `−` или `1`–`4` (1 игровой день = 1 секунда на скорости 1) |
| Панель страны | клик по стране на карте |
| Наука / фокусы | `R` / `F` |
| Мировые новости и календарь выборов | `N` |
| Карта идеологий ⇄ блоков | `I` |
| 3D-глобус ⇄ 2D-карта | `M` |
| Меню, сохранение | `Esc` |

**Война**: страна → «Обосновать войну» → дождаться → «Объявить войну». На карте появится **линия фронта**.

**Армии**: дивизии воюют в составе армий — фишек на карте. Кликните по фишке, затем по своей земле — армия
пойдёт туда; по соседней вражеской — начнёт наступление (правый клик тоже работает). Бой идёт каждый день:
контроль врага падает, пока у армии есть организация. Захватив землю, армия входит в неё — фронт сдвигается.
Земли без армии защищает только ополчение. Новые дивизии попадают в резерв в столице — из них можно
собрать армию или пополнить существующую.

**Шаблоны дивизий**: кнопка «Шаблоны» внизу (или D) открывает конструктор. Дивизия собирается из батальонов
(пехота, мотопехота, танки, артиллерия, ПТ): танки сильны в атаке и прорыве, пехота держит оборону и организацию,
ПТ гасит танки противника, пешая пехота замедляет марш. Новые дивизии набираются по шаблону, выбранному внизу.

**Фокусы**: у каждой державы своё дерево. Во втором ряду выбирается политический путь: один сохраняет
нынешнего лидера, два других приводят к власти другого человека и меняют идеологию (например, в России —
Путин, Навальный или Зюганов; в США — Трамп, Байден или Сандерс; в Китае — Си Цзиньпин, Ли Кэцян или военные).

**Политика**: в панели страны видны лидер, идеология, популярность партий и дата выборов. Можно поддержать
партию (деньги и СМИ на 120 дней), вмешаться в выборы (за 180 дней до них) или устроить переворот. Страны с
близкой идеологией охотнее вступают в ваш блок, а идеология вашей державы даёт свои бонусы. В режимах выборы
управляемые: власть проигрывает, только если её поддержка упала ниже 30%.

**Украина**: полноценная держава со своим деревом фокусов (Порошенко, Зеленский или Бойко), блоком ГУАМ и
событиями. Между Россией и Украиной есть своя шкала напряжённости: она медленно растёт, её двигают события,
фокусы и решения; на 100% начинается развязка — вплоть до войны.

**ВДВ**: армия из воздушно-десантных дивизий (шаблон «Воздушно-десантная дивизия», батальоны ВДВ) может
высадиться на любую вражескую землю в радиусе 2200 км — даже без общей границы. Первые дни — внезапность (×1,25 к атаке),
но организация тает быстрее, а не взяв цель, десант теряет 40% дивизий. Выберите армию и кликните по цели.

**Запад и Украина**: шкала «Украина — Запад» (доверие к Киеву) зависит от правительства Украины, коррупции, фокусов
и решений. Если Россия нападёт, Запад вводит санкции и раз в 30 дней шлёт пакеты оружия — тем больше, чем выше доверие.
Если за США играет человек, решает он.

**Партии**: у стран настоящие названия партий («Единая Россия», «Слуга народа», «ХДС/ХСС» и т. д.), они в
`js/parties.js`. На карте названия стран растянуты вдоль страны и изогнуты по её форме, как в HOI4 (`js/labels.js`).

**Новости**: окно «Мировые новости» (N) — выборы, перевороты, войны и кризисы по всему миру, плюс календарь
ближайших выборов. События с выбором приходят по реальным датам 2018–2023 годов (дело Скрипалей, торговая
война, пандемия, Карабах, Кабул…) и случайно. Временные эффекты событий — «национальные духи» (санкции,
пандемия, торговая война) — видны в подсказке у портрета лидера.

**Победа**: 55% мировой промышленности или захват столиц обеих соперничающих держав.
**Поражение**: потеря своей столицы или ядерная зима (7 радиоактивных пустошей на планете).

## Устройство проекта

```
index.html            разметка интерфейса и иконки (SVG прямо в файле)
css/style.css         весь внешний вид: тёмная тема, панели, окна
js/util.js            форматирование чисел и дат, кубики, «шина событий» Bus
js/focuses.js         деревья национальных фокусов для каждой державы
js/data.js            ВЕСЬ БАЛАНС: стартовые ресурсы, страны, блоки, технологии, державы
js/politics.js        идеологии, правительства 2018 года, выборы, вмешательство, перевороты
js/events.js          события с выбором, мировые новости по датам и случайные новости
js/geo.js             загрузка карты, центры стран, поиск соседей по границам
js/combat.js          боевой калькулятор: атака, оборона, броски, потери, шансы
js/ai.js              ИИ-директор: рост армий, мобилизация, наступления, мир, ядерный ответ
js/game.js            состояние игры, ежедневный такт и все действия игрока, сохранения
js/map.js             3D-глобус (globe.gl + Three.js) и запасная 2D-карта (Canvas)
js/ui.js              интерфейс: панели, журнал, окна, подсказки
js/audio.js           звуки, синтезированные Web Audio (без аудиофайлов)
js/main.js            запуск с запасными вариантами и игровой цикл
data/countries.js     границы стран Natural Earth 1:110m с русскими названиями
vendor/globe-bundle.min.js   Three.js 0.186 + globe.gl 2.46 одним файлом
```

Модули не вызывают интерфейс напрямую: игра сообщает о событиях через `Bus.emit(...)`, а интерфейс
на них подписан. Поэтому логику можно менять, не трогая отрисовку, и наоборот.

### Хочу поменять баланс

Всё в `js/data.js`:
- `CFG` — стартовые ресурсы, цена дивизии, скорость роста, порог ядерной зимы, условие победы;
- `COUNTRY_OVERRIDES` — заводы, дивизии и укрепления конкретных стран;
- `FACTION_MEMBERS` — кто в каком блоке;
- `TECHS` — технологии; фокусы — в `js/focuses.js`;
- `GOV_2018` в `js/politics.js` — лидеры, кандидаты, популярность партий и даты выборов;
- `EVENTS`, `WORLD_NEWS`, `RANDOM_NEWS` в `js/events.js` — события и новости.

После правок обновите страницу. Если браузер упрямо показывает старую версию, увеличьте число `?v=22`
в `index.html` у подключённых файлов.

## Надёжность

- Карта: локальный файл → три CDN по очереди → аварийная схематичная карта.
- 3D-движок: локальный бандл → CDN → 2D-карта на Canvas.
- Потеря 3D-контекста видеокарты → автоматическое переключение на 2D.
- Ошибка в одном игровом дне не останавливает игру.
- Две ячейки сохранения: ручная и автосохранение каждые 30 игровых дней.

## Как пересобрать 3D-бандл (если понадобится)

```bash
npm install globe.gl three esbuild
```

Файл `entry.js`:

```js
import * as THREE from 'three';
import Globe from 'globe.gl';
window.THREE = THREE;
window.Globe = Globe;
```

```bash
npx esbuild entry.js --bundle --minify --format=iife --outfile=vendor/globe-bundle.min.js
```
